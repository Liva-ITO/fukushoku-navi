# 言葉づかいチェック

このサービスを使うのは、メンタルの不調で休職している本人と、会社の人事・産業保健スタッフ。
言葉ひとつで、本人が「責められた」「急かされた」と感じることがある。画面の言葉を、次の原則で見直す。

## 調べる場所

1. `src/constants/labels.ts`（画面の言葉はここに集める決まり）
2. `src/**/*.tsx` の中に、labels.ts を通さずに直接書かれた日本語（あれば、それ自体を指摘する）

## 本人向けの原則

| 原則 | 引っかかる例 | 言い換えの例 |
|---|---|---|
| 押しつけない | 「〜してください」「〜しなければ」「必ず」 | 「やれるならやってみよう」「〜しておこう」 |
| 責めない | 「できませんでした」「未達成」、点数・達成率・連続日数、×印や警告色 | 何も出さない／「書けた日も、書けなかった日も、どちらも大丈夫です」 |
| 選ぶのは本人 | 「次は〜です」と一つに決めつける | 選択肢として並べる。「様子を見る」も選択肢に入れる |
| 後退と言わない | 「後退」「悪化」「逆戻り」「段階が下がる」 | 「ペースを合わせる」「ペースを調整中」 |
| 「休職者」と呼ばない | 本人画面の「休職者」「休職ポータル」 | 名前で呼ぶ／主語を省く |
| 「戻る」より「進む」 | 「元に戻る」「復帰を目指す」 | 「次の一歩」「進む」 |

急性期の画面は特に厳しく見る。やることを求める言葉、赤いバッジや未読の数字はすべて指摘する。

## 会社（人事・産業保健）向けの原則

1. やることが先に来る：開いたら「今日、何をすればいいか」がわかるか
2. 本人を急かす言葉を渡さない：人事が送る例文も、本人向けの原則に合わせる
3. 見えないものは「見えない」と書く：記録の中身が見えないことを隠さず、理由と一緒に示しているか

## 出し方

- 原則に引っかかる言葉ごとに「場所／いまの言葉／どの原則か／言い換えの案」を表で出す
- 言い換えは案にとどめ、勝手に書き換えない。決めるのは伊藤さん
- 引っかかるものがなければ「原則に引っかかる言葉はありませんでした」とだけ書く
